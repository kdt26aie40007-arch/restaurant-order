# サニーテーブル メニュー・オーダーシステム

## 概要

ファミリーレストラン「サニーテーブル」で、お客さんがテーブルからメニューを見て注文し、最後にお会計まで行えるシステムです。
ブラウザだけで動き、注文データはブラウザ内（localStorage）に保存します。

## 起動方法

インストールは不要です。ブラウザ（Chrome / Edge など）があれば動きます。

```
git clone https://github.com/kdt26aie40007-arch/restaurant-order.git
cd restaurant-order
```

1. clone したフォルダの中にある `index.html` をダブルクリックして、ブラウザで開きます。
2. 画面右上の「テーブル番号」に 1〜30 の数字を入力してから注文します。

## システム構成

### 使用した技術

HTML / CSS / JavaScript（ライブラリなし）

### ファイル構成

| ファイル | 役割 |
|---|---|
| index.html | 画面の骨組み（ヘッダー、メニュー、カート、注文履歴・お会計） |
| style.css | 見た目（色、レイアウト、スマホ表示） |
| menu.js | 店名・メニュー・アレルゲン・カテゴリのデータ（料理ごとの画像のパスもここに書く） |
| images/ | 料理の画像（h1.svg など料理の id と同じ名前）と、画像がないときの代わりの画像 noimage.svg |
| app.js | 画面の表示と動き（メニュー表示、カート、入力チェック、おすすめ、注文の保存、会計） |
| CLAUDE.md | 開発で使った Claude Code 向けのメモ |

## データ設計

### 保存方法

注文データはブラウザの localStorage に、キー `sunnyTable.orders` で JSON 形式で保存します。
会計の記録（お預かり金額・おつり）は、キー `sunnyTable.payments` に保存します。

理由：サーバーやデータベースを用意しなくても、`index.html` を開くだけで注文を記録でき、ページを再読み込みしても消えないためです。
同じブラウザで開いている間はデータが残ります（ブラウザのサイトデータを消すと消えます）。

### データの形

| データ | 項目 |
|---|---|
| メニュー（menu.js） | id, image（画像のパス）, category（カテゴリ）, name（料理名）, price（税込価格）, allergens（アレルゲンの配列）, recommended（店長のおすすめか）, tags（料理の特徴：ボリューム・定番・ヘルシーなど）, description（説明） |
| 年代・性別（menu.js） | AGE_GROUPS（年代ごとに、どの特徴を何点で好むか）, GENDERS（性別ごとの加点。「回答しない」は加点なし）, TAG_LABELS（特徴の説明文） |
| 注文（sunnyTable.orders） | id, table（テーブル番号）, items（料理ごとの id, name, price, qty）, total（合計金額）, orderedAt（注文日時）, paid（会計済みか）, paidAt（会計日時） |
| 会計（sunnyTable.payments） | table（テーブル番号）, orderIds（まとめて会計した注文の id）, total（合計）, received（お預かり金額）, change（おつり）, paidAt（会計日時） |

## 画面と機能

### 画面構成

- **ヘッダー**：店名「サニーテーブル」とテーブル番号の入力欄
- **メニュー（左側）**
  - アレルギーの食材を選ぶチェックボックス（特定原材料8品目）と注意書き
  - あなたへのおすすめ（年代・性別を選ぶと、お食事・サイドかデザート・ドリンクを1品ずつ理由付きで表示）
  - 人気ランキング（注文数の多い料理 TOP3）
  - カテゴリのタブ（すべて / 店長のおすすめ / ハンバーグ・ステーキ / パスタ / サラダ・サイド / キッズ / デザート / ドリンク）
  - メニューカード（料理の画像、料理名、おすすめマーク、説明、アレルゲン、価格、数量、追加ボタン）
- **カート（右側）**：注文前の料理一覧、数量の増減・削除、合計金額、おすすめの提案、注文ボタン
- **ご注文履歴・お会計（右側）**：そのテーブルの未会計の注文一覧と合計、お預かり金額の入力欄、おつりの表示

画面幅が狭いとき（スマホなど）は、メニューの下にカートとお会計が並びます。

### 要件と機能の対応

| No | 要件 | どの機能で満たしたか |
|---|---|---|
| 1 | 店名表示 | ヘッダーに「サニーテーブル」を表示（ブラウザのタブにも表示） |
| 2 | メニュー表示 | カテゴリ別のタブとメニューカードで、料理の画像・料理名・説明・価格・アレルゲンを表示 |
| 3 | 注文 | 数量を入れてカートに追加し、「注文する」で確定 |
| 4 | 注文データの記録 | 確定した注文を localStorage に保存し、「ご注文履歴」に表示 |
| 5 | おすすめ機能 | 年代・性別を入力すると、料理の特徴の点数から「あなたへのおすすめ」を3品、理由付きで表示（まとめて追加も可能）。店長おすすめマークと店長のおすすめタブ。カートの中身に合わせて、ドリンクバーやデザートを提案。記録した注文データから人気ランキング TOP3 を表示 |
| 6 | 会計 | テーブルごとに未会計の注文を合計し、お預かり金額からおつりを計算して会計済みにする |
| 7 | 入力チェック | 数量（1〜10の整数、1品10個まで）、テーブル番号（1〜30の整数）、空のカートでの注文、お預かり金額（整数・合計以上・100万円まで）、おすすめの年代の未選択をチェックし、エラーを表示 |
| 8 | アレルギー対応 | 全メニューにアレルゲンを表示。選んだアレルゲンを含む料理は追加・注文できなくする。8品目以外や混入の可能性についての注意書きを表示 |

## 自分で決めたこと

<!-- Claude Code が実装で決めた内容です。自分の考えと違うところは直してください。 -->

| 決めたこと | 理由 |
|---|---|
| HTML / CSS / JavaScript だけで作る | インストール不要で、`index.html` を開くだけで動かせるため |
| 注文データを localStorage に保存する | データベースを用意せずに、再読み込みしても注文が残るようにするため |
| 価格はすべて税込で表示する | ファミレスのメニュー表示に合わせ、会計で税計算をしなくて済むため |
| テーブル番号を 1〜30 にする | 一般的なファミレスの席数を想定したため |
| 数量は1品につき10個まで | 入力ミス（桁の打ち間違いなど）を防ぐため |
| アレルゲンは特定原材料8品目（卵・乳・小麦・えび・かに・そば・落花生・くるみ） | 表示が義務付けられている品目で、利用者にもわかりやすいため |
| アレルゲンを含む料理は隠さず、グレー表示にして注文できなくする | どの料理が食べられないのか、理由と一緒にわかるようにするため |
| メイン料理を頼むとドリンクバー、次にデザートを提案する | ファミレスでよくある組み合わせで、追加注文につながるため |
| 会計はテーブル単位で、お預かり金額を入力してから確定する | 押し間違いで会計済みにならないようにし、おつりも計算できるようにするため |
| お預かり金額の上限を100万円にする | 桁の打ち間違いによる、ありえない金額を防ぐため |
| 人気ランキングは全テーブル・全期間の注文数で TOP3 を出す（同数ならメニュー順） | 記録した注文データをおすすめに活かし、店全体の人気がわかるようにするため |
| アレルギーに「8品目以外は表示していない」「混入の可能性がある」と注意書きを出す | 表示がすべてだと誤解されないようにするため。実際の飲食店でも同様の表示をしている |
| おすすめは年代を必須、性別を任意（「回答しない」あり）にし、性別の影響は年代より小さくする | 性別だけで好みを決めつけないようにし、答えたくない人も使えるようにするため |
| おすすめはお食事・サイドかデザート・ドリンクから1品ずつ選ぶ | 1回の食事としてそのまま注文できる組み合わせにするため |
| お子さまメニューは12歳以下を選んだときだけおすすめする | 大人にお子さまメニューをすすめないようにするため |
| おすすめでも、選んだアレルゲンを含む料理は出さない | アレルギーのある人に食べられない料理をすすめないようにするため |
| 料理の画像はひとまずイラスト（SVG）にし、写真に差し替えられるようにする | 著作権を気にせずすぐ用意でき、あとで写真を用意したときも menu.js のパスを変えるだけで済むため |
| 画像が見つからないときは代わりの画像を出す | 差し替えでファイル名を間違えても、画面が崩れないようにするため |
| 見た目は深い木目の背景・生成り色のカード・明朝体の見出しにする | 落ち着いた上品な雰囲気にし、白っぽいカードを木目の上に置くことで料理と文字を読みやすくするため |
